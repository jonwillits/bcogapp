# Module 10 word norms

The scripts that fetched the public word norms Part 1's unrelated lists and Part 2's word sets were chosen against, run once on Jon's Mac. The norm files and the virtual environment live outside the repo and outside Box, at `~/Documents/Projects/bcogapp_data/m10/`; only these scripts and the chosen words (in `src/sim/memory/words/`) are in git. Never `pip install` inside Box.

Set up: `python3 -m venv ~/Documents/Projects/bcogapp_data/m10/venv && ~/Documents/Projects/bcogapp_data/m10/venv/bin/pip install -r requirements.txt`. Run every script with `python -I <script>` from outside the data folder.

1. `fetch_norms.py` — downloads the two norm files into the data folder:
   - **Brysbaert, Warriner and Kuperman (2014)**, *Concreteness ratings for 40 thousand generally known English word lemmas*, Behavior Research Methods 46, 904–911. The CRR site's own path (`crr.ugent.be/papers/Concreteness_ratings_Brysbaert_et_al_BRM.txt`) returned 404 on 2026-10-25; the file was taken from the public GitHub mirror `ArtsEngine/concreteness`, which carries the authors' file unchanged (39,954 rows; columns Word, Bigram, Conc.M, Conc.SD, Unknown, Total, Percent_known, SUBTLEX, Dom_Pos). Its SUBTLEX column is the raw SUBTLEX-US count and Dom_Pos the dominant part of speech.
   - **SUBTLEX-US** (Brysbaert and New, 2009, *Moving beyond Kučera and Francis*, Behavior Research Methods 41, 977–990; part-of-speech columns from Brysbaert, New and Keuleers, 2012), from the Ghent University page `https://www.ugent.be/pp/experimentele-psychologie/en/research/documents/subtlexus`: `subtlexus1.zip` (the Excel file with PoS and Zipf information) and `subtlexus2.zip` (the plain text version, 74,286 words). The frequency per million used below is `FREQcount / 51` (the corpus is 51 million words).
2. `candidates.py` — writes `candidates.txt`: words with concreteness ≥ 4.5, SUBTLEX-US frequency ≥ 5 per million, 3 to 8 letters, a dominant part of speech of Noun, and one or two syllables by a vowel-group count. **The lists themselves were chosen by hand from this pool** and typed into `src/sim/memory/words/lists.ts` and `sets.ts`; `chosen.py` then checks every chosen word against the norms and prints each word's concreteness and frequency, which the as-built notes quote.
